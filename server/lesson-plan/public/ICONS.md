# 章节操作图标来源

来自用户指定的 [iconfont 阿里巴巴矢量图标库](https://www.iconfont.cn/)，使用公开项目 2678727 中的 `icon-edit`、`icon-close`、`icon-check`。

- [项目](https://www.iconfont.cn/manage/index?manage_type=myprojects&projectId=2678727)
- [公开示例及引用说明](https://at.alicdn.com/t/project/2678727/caef142c-804a-4a2f-a914-ae82666a31ee.html)
- [原始 SVG symbol 素材](https://at.alicdn.com/t/font_2678727_za4qjydwkkh.js)

仅提取三个图标的 SVG path，内联于 `plan.js` 的 `sectionIcons`，使用 `currentColor`。未执行、引入远程JavaScript，也不在运行时请求外部字体或脚本。
