# 问卷管理正式实现

用户已确认原型验收通过，授权正式完善。范围为已验收的制作、WorkBuddy初版、教师确认、同网络回收、分析导出及既有学情看板整合。

1. 服务端持久化：校验题型、发布冻结、名单快照、并发修订、状态转换、重复和幂等提交；公开接口仅返回题面，禁止暴露教师答卷与名单。
2. 沿用验收页面，移除演示控件，接入真实课程和API；学生端独立页面，发布后生成局域网链接与二维码。
3. WorkBuddy交接复用已有受限CLI与初版校验，任务保存在正式数据目录；不向模型传递名单及答卷。
4. 在既有学情看板加入本课程问卷概览，不混入原型数据，不合并量表或推断学生能力。
5. 隔离服务与数据目录验证正式流程、匿名隐私、权限、并发、CSV导出和生成初版接入，保持原型可回看。

上述范围已实现并通过隔离开发检查；真实WorkBuddy三题初版生成与草稿导入已通过。正式平台已启动，入口与测试证据见[正式交付与验收](正式交付与验收.md)。当前用户验收：原型通过；正式功能待验收。测试未使用真实教学数据。
