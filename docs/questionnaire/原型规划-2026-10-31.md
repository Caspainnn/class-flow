# 问卷管理原型规划

日期：2026-10-31。方案已确认；当前已制作隔离交互原型，待用户验收，尚未实现正式功能。

进展：方案已获用户同意，现已制作隔离可点击原型，入口、测试证据与原型边界见[原型交付与验收](原型交付与验收.md)。原方案下列条目仍作为正式开发的需求依据。

增量：用户已确认接入 WorkBuddy 辅助制作，现可真实生成题目初版，导入后由教师逐题修改确认；默认匿名和演示回收边界有效。具体见 [WorkBuddy接入计划](WorkBuddy接入计划.md)。

## 1. 已确认的方向

- 入口位于「学情分析 → 问卷管理」，用于向学生发放问卷，再查看和分析反馈。
- 默认匿名，也可选择实名。用户已在本对话确认。
- 首版用于课堂内、老师电脑与学生手机处于同一可互通网络的场景。用户已确认；不在本轮引入公网部署或收费服务。
- 先审查原型方案，再制作可点击原型；原型通过后正式开发。
- 目标是让老师少填必要项，顺畅完成创建、发放、回收和分析，不引入复杂的调研项目管理。

## 3. 信息架构与核心流程

导航：学情分析 → 问卷管理。

教师新建流程用三步：**填写问卷 → 设置发放 → 预览发布**。「上一步」统一位于内容底部左侧。

教师使用流程：进入列表 → 新建或复制已有问卷 → 编辑题目 → 设置课程和身份方式 → 预览 → 发布 → 展示二维码或复制链接 → 看回收 → 停止回收 → 查看分析 → 归档。

学生流程：扫码 → 查看问卷说明 → 实名问卷才填写学号、姓名 → 作答 → 校验并提交 → 看到提交成功。匿名问卷直接进入题目，不先要求身份输入。

已发布问卷的详情中使用「发放与回收 / 结果分析」两个标签；不把发放、等待、结束和分析继续拉成长步骤条。

## 4. 原型页面清单

| 页面 | 内容与主要操作 | 要验证的交互 |
| --- | --- | --- |
| 问卷列表 | 课程筛选、标题搜索、全部/草稿/回收中/已结束/已归档；新建、复制、查看或继续编辑 | 状态和回收量清楚；首版用紧凑列表，不为无图片的问卷制作大封面 |
| 填写问卷 | 标题、可选说明、题目卡片；新增单选/多选/量表/简答 | 直接编辑题干选项、复制、上下移动、删除、必答开关；保留未保存输入 |
| 设置发放 | 课程、默认匿名/可选实名、可选截止时间 | 切换实名才出现名单及回收率说明；未录名单时不能发布实名问卷 |
| 预览发布 | 完整手机预览、课程、身份方式、题量、截止时间摘要 | 返回编辑不丢内容；明确点击「发布并生成二维码」才开始回收 |
| 发放与回收 | 二维码、可复制链接、问卷状态、已回收份数、刷新时间、停止回收 | 二维码可放大且操作可见；实名才显示名单进度与未提交名单 |
| 结果分析 | 概览、逐题分布、量表统计、简答原文、答卷明细、导出 | 切换题目和筛选条件时保留上下文；结果与分母对应 |
| 学生手机填写 | 标题、说明、匿名/实名提示、题目、提交按钮 | 手机单列滚动，输入控件足够大；必答校验就近显示并定位首个错误 |
| 学生提交与不可用状态 | 提交成功、已提交、已截止、已停止、链接无效、网络失败 | 不假成功；网络失败保留本页输入，可安全重试 |

问卷列表建议列：问卷名称与简短说明、课程、身份方式、状态、回收量、更新时间、操作。常用操作直接露出；归档、删除等放入「更多」。

## 5. 编辑与最少必要项

草稿至少需要标题才能保存；发布前必须有关联课程、至少一道有效题目。课程优先沿用进入学情分析时的课程选择。

| 项目 | 默认或规则 |
| --- | --- |
| 问卷标题 | 必填；例如「本节课学习反馈」 |
| 问卷说明 | 选填，不要求老师先写调查目的等长文本 |
| 身份方式 | 默认匿名，设置发放时可改成实名；发布后锁定 |
| 截止时间 | 默认不设置，老师手动停止；可选具体截止时间 |
| 发放范围 | 一份问卷对应一门课程；多门课程先使用「复制问卷」分别发放 |
| 单选 | 至少两个非空选项；默认必答；不设置标准答案 |
| 多选 | 至少两个非空选项；默认必答；不在首版增加选项跳转、复杂选择数量约束 |
| 量表 | 默认1–5分，必须显示两端含义；默认必答；不默认计算综合评分 |
| 简答 | 默认选填；给出字数上限，建议500字 |

题目卡片包含题型、题干、内容编辑区、必答开关和操作。初版不做树形层级、矩阵题、题目分支、附件上传和随机题序。

复制已发布问卷只复制题目和发放设置，创建新草稿、新链接，不复制答卷与统计结果。

## 6. 匿名与实名的明确区别

| 行为 | 匿名：默认 | 实名：可选 |
| --- | --- | --- |
| 学生输入身份 | 不要求学号、姓名 | 学号、姓名，与发布时课程名单核对 |
| 答卷保存的身份字段 | 不保存学生身份关联 | 保存对应课程内学生标识及必要名单快照 |
| 回收指标 | 已回收多少份答卷 | 已提交人数 / 发布时目标人数 |
| 未提交名单 | 不提供 | 提供 |
| 个体画像关联 | 不关联 | 可展示该学生本次问卷回答；不自动转成预警或学习能力评分 |
| 重复提交 | 同一浏览器提交后提示已提交，重试使用同一提交标识；不能宣称严格一人一次 | 同一问卷同一名单学生仅接受一次正式答卷；并发提交由服务端兜底 |
| 限制说明 | 换设备或清除浏览器记录可能再次提交，不能验证实际参与人数 | 名单核对不是独立账号认证，首版不宣传为强身份认证 |

学生匿名页提示：「本问卷为匿名填写，不需要学号和姓名。」实名页提示：「本问卷为实名填写，回答将关联你的课程名单信息。」

不使用共享校园网络的IP地址判定“一人一次”，避免整班学生互相阻塞。匿名问卷不借用签到身份或设备指纹悄悄关联学生。

## 7. 发布、回收与版本

- 发布前可自由编辑草稿，教师预览不会产生正式答卷。
- 发布时固定题目、选项、身份方式及课程范围；实名问卷保存当时的目标名单快照作为回收率分母。
- 发布后不直接改题、换选项或切换匿名/实名。需要修改时使用「复制并编辑」，避免前后回答混入不同题面。
- 名单后续增删不静默改变已发布实名问卷的统计分母。首版不在回收期间调整目标名单。
- 二维码与链接打开同一份问卷。学生手机页面不展示其他学生信息或统计结果。
- 发放页使用学生可访问的局域网地址，不能把`127.0.0.1`发给学生；提示同一网络及老师电脑需保持运行。网络是否互通仍取决于现场环境。
- 首版仅提供“复制链接/展示二维码”，不自动替教师发消息到群，也不声称已送达每一名学生。
- 手动停止回收使用红框按钮与确认弹窗。截止时间到达或老师停止后，提交由服务端拒绝；正在填写的学生看到原因，当前输入不被直接清空。
- 已结束问卷可恢复回收，前提是题目、身份、范围不变，截止时间有效；已有答卷和原分母保留。
- 已结束问卷可归档。归档后不能继续回收，可查看、导出或复制；取消归档回到已结束状态。
- 删除草稿需确认；有答卷的问卷首版优先引导归档，暂不提供清空答卷或永久删除回收数据的入口。
- 课程被删除时，关联问卷应停止新回收并保留历史结果及课程名称快照；正式开发时需补齐该联动，不能把旧链接留成无人管理的回收入口。

状态流：草稿 → 回收中 → 已结束 → 已归档。已结束可恢复回收，已归档可取消归档回已结束。

## 8. 数据分析怎么展示

### 概览

匿名问卷：已回收份数、题目数量、开始/结束时间、回收趋势。不显示人数回收率，不显示未交人数，不把浏览次数当成发放人数。

实名问卷：目标人数、已提交人数、未提交人数、回收率。回收率 = 目标名单内已提交的唯一学生数 / 发布时目标名单人数。提交时间分布用于回收趋势。

零答卷时显示「暂未收到答卷」与发放入口；均值和分布用“—”或空态，不编造统计或分析建议。

### 逐题

| 题型 | 首版分析 | 口径 |
| --- | --- | --- |
| 单选 | 水平条形图、选项份数和占比 | 分母为本题有效作答份数，另列未答 |
| 多选 | 各选项被选份数、占比 | 分母为本题有效作答份数；多项可同时选择，总占比可能超过100%，不用饼图 |
| 量表 | 1–5分分布、均值、有效作答数 | 未答不记0分；不同量表题不默认混算；分值必须保留题目含义 |
| 简答 | 原文列表、题内搜索、教师标记主题、各主题条数 | 不伪造AI洞察；主题计数以已标记回答为准，可多主题，未标记数量单列 |

筛选首版只保留问卷内提交时间、某道选择题的答案。筛选后，概览和逐题统计共同使用同一批答卷，并显示“当前筛选N份 / 全部M份”；实名目标人数分母仍是发布时名单，不能拿筛选后答卷数当目标人数。为避免误读，筛选结果默认展示“筛选答卷占比”，总回收率仍单独列为全量指标。

暂不提供跨问卷综合学情分、不同题面直接比较、自动判定学生能力及自动生成预警。实名问卷若进入个体画像，仅展示该问卷的直接回答证据。

首版分析不依赖AI。后续如添加简答主题建议或教学建议，应在用户确认接入后再做；需能回到原回答和统计依据，不能把模型推测写成学生事实。

### 明细与导出

- 匿名明细仅含答卷编号、题目回答及必要提交信息，不出现学号姓名列，也不显示“未提交学生”。
- 实名明细含名单身份、提交状态及回答；未提交名单独立可见。
- Excel建议分为「问卷与统计口径」「逐题汇总」「答卷明细」；实名再附「未提交名单」。
- 当前有筛选时，让老师选择“全部结果”或“当前筛选”，导出中记录筛选条件。
- 正式实现要将学生简答当作文本导出，防止被表格软件当公式执行。

## 9. 原型样例与可验证数字

所有样例均为合成数据，页面明显标注演示数据。

- 样例A：匿名「本节课学习反馈」，回收36份，不展示“36/47人”或76.6%回收率。
- 单选「本节课节奏」：偏快14份、适中18份、偏慢4份，共36份。
- 选填量表样例：1至5分分别1、2、6、17、8份，有效34份、未答2份，均值131/34，显示3.85/5。
- 样例B：实名「课前知识自评」，发布时名单47人、已提交36人，未提交11人，回收率76.6%。所有身份使用合成学号姓名。
- 另备草稿、零回收、已结束、已归档、网络错误、提交中与重复提交状态。

## 10. 必要数据字段（供后续正式开发评审）

| 对象 | 最小字段 | 说明 |
| --- | --- | --- |
| 问卷 | id、title、description、courseId、courseNameSnapshot、identityMode、status、createdAt、updatedAt | identityMode默认anonymous |
| 题目 | id、order、type、title、required、options或scale | 选项使用稳定id，不靠选项文字作为关联键 |
| 发布快照 | publishedAt、questionVersion、题目与设置快照、deadline、shareToken | 版本固定；shareToken只用于访问该份学生问卷，不等同教师权限 |
| 实名目标 | 发布时的名单快照、targetCount | 只在实名模式用于身份核对和固定分母 |
| 答卷 | id、surveyId、questionVersion、submittedAt、requestId、answers | requestId用于提交重试幂等；答案按题目id保存 |
| 实名答卷身份 | courseId、studentId、必要姓名快照 | 匿名答卷不保存这些关联字段 |
| 教师主题标记 | responseId、questionId、tags | 与学生原文分开保存，保留原文 |

这里不固定数据库或接口实现，也不在规划阶段引入外部服务。

## 11. 交互与异常状态

- 发布校验：未关联课程、缺题干、缺选项、题目为空等，就近显示错误并定位，不清空输入。
- 编辑取消：无改动直接返回；有改动时确认保存或放弃。上一步位于内容底部左侧。
- 停止回收、删除草稿：红框按钮、明确对象及后果、默认聚焦安全操作；请求中防重复，失败留在弹窗。
- 复制链接、保存成功：底部轻消息，不额外弹确认框。
- 发布/加载/提交失败：对应区域持续提示原因和重试入口；学生输入保留。
- 提交中：按钮显示“正在提交”，防止重复点击；只有服务端确认成功才显示成功页。
- 答卷已提交：实名显示该学生已提交；匿名仅说明本浏览器已提交，不宣称识别了真实个人。
- 已结束、链接无效、老师电脑离线：分别说明状态，不能都写“提交失败”。离线时不声称问卷已结束。
- 统计更新：发放页标明最近刷新时间；更新数字不重置选中的分析题目、筛选项或已展开的原文。
- 原型模拟发布、提交和统计，但必须与正式课程、名单、答卷隔离；不发送真实问卷。

## 12. 首版范围与原型验收

首版包含：一门课程、四类题型、匿名/实名、三步创建、学生手机填写、链接/二维码发放、回收进度、结束/恢复/归档、逐题统计、简答原文与教师主题标记、明细与Excel导出。

后续再评估：问卷模板库、多课程一次发放、独立班级、题目跳转/矩阵/随机、开放公网回收、强账号认证、AI分析、自动催收、跨问卷趋势及复杂交叉分析。

可点击原型重点验收路径：

1. 不改默认身份方式，创建匿名问卷 → 手机预览 → 发布 → 模拟提交 → 看见36份回收与逐题图表，无名单回收率。
2. 改选实名 → 核对目标名单人数 → 模拟回收 → 查看76.6%回收率与11人未提交。
3. 有未保存编辑时返回，确认后才丢弃；上下移动题目不丢内容。
4. 停止回收后学生不能再提交；老师能看旧答卷、恢复原问卷或复制新问卷。
5. 多选占比、量表缺失值和筛选后的统计口径正确；零结果没有假分析。
6. 手机与桌面预览完整，主要按钮不被超长内容挤到视口外，步骤返回位置一致。

方案审查重点：页面是否足够简洁、首版题型是否够用、分析是否便于教师采取下一步行动。匿名默认与课堂内同网络场景已确认，无需再次询问。
