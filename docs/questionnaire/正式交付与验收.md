# 问卷管理正式功能交付

日期：2026-11-01。原型已获用户验收；正式实现与开发自测完成，正式业务验收待用户进行。

## 入口与使用

- 问卷管理：<http://127.0.0.1:3000/questionnaires#list>，正式侧栏「学情分析 → 问卷管理」。
- 学情看板：<http://127.0.0.1:3000/xueqing?tab=dash>，按当前课程显示问卷发布、回收、累计答卷及最近问卷。
- 原型仍可单独在3013查看；不会把原型浏览器存储或合成答卷迁入正式数据。

教师流程：填写基本信息（课程、默认匿名/可选实名、可选截止时间）→ 选择方式 → 手动编写或WorkBuddy填写需求并生成 → 审阅题目 → 手机预览并明确发布。题目支持上移、下移和红字删除；不提供拖动和复制题目。发布后题目和身份锁定，复制问卷可以另行修改。

发布成功后展示学生访问链接与二维码。老师电脑需保持运行；学生与老师处于可互通网络。默认沿用平台已选择的局域网地址，可通过已有 `PUBLIC_ORIGIN` 配置覆盖。手机可达性、防火墙及校园无线隔离仍需现场确认，不能把本机HTTP联调当作手机真机验收。

WorkBuddy使用现有连接设置，实际执行为本地CodeBuddy CLI，仅开放Read/Write/Edit，不开启Bash。后台生成可在问卷列表通过「继续制作」返回；完成直接进入可编辑初版，确认后才发布。只交接教师需求，不交接名单和学生答卷。

## 数据与校验

- `data/questionnaires.json`：问卷、发布名单快照、答卷和全局修订号，采用现有原子文件写入。正式课程与名单来自现有平台。
- `data/questionnaire-ai/`：生成任务、需求和交付文件。原型仍使用独立 `.tmp-questionnaire-ai/`。
- 教师操作仅本机开放；学生入口仅公开题面与提交接口，不返回课程名单或已有答卷。教师端不返回匿名设备标识和提交幂等凭证。
- 匿名按答卷份数统计，不显示名单回收率；同浏览器cookie限制重复提交，不声称严格一人一份。实名按发布时名单核对学号和姓名，仍不是强账号认证；名单变动不会改写既有问卷分母。
- 服务端最终校验题型、长度、选项、必答、截止、状态和重复提交。同一提交请求重试不会重复计数；服务返回成功前学生页不显示成功。网络失败保留输入。
- 教师保存带修订号，答卷或其他教师页已更新时拒绝覆盖，保留当前编辑内容并提示重试。保存草稿明确保持草稿状态；发布必须由教师点击。
- 柱状图和环形图同时展示；多选柱状图以有效作答为分母，环形图以总选中次数为分母。不同量表不混算，主观反馈不用于自动学生能力评分或预警。
- 未提交名单为页内表格；简答保留原文与搜索，不展示教师标记。导出为带筛选说明的CSV，可在Excel打开，不伪装成XLSX。

# 回收截止时间调整（2026-11-01）

新建问卷默认显示回收截止时间输入框，需填写晚于当前时间的日期时间；勾选“不设置截止时间”后清空并禁用时间输入，由教师手动停止回收。取消勾选后恢复必填。选择随草稿保存，兼容旧问卷已有的手动停止设置。复制问卷重新要求填写截止时间。

已通过隔离模型、前端实际事件处理器及服务层测试：空值拦截、勾选切换、截止时间随发布保存、不设截止时间的持久化及服务端发布校验。
