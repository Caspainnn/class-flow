# 固定侧栏与内容工作区

问题：自动批改的全局 `.sub` 规则给侧栏子菜单增加上边距；原菜单使用整页跳转，各页面又重新注入侧栏，造成刷新与位置跳动。

实现：

- 侧栏子菜单明确固定上边距与行高。
- 新增 `workspace.html` / `workspace.js`，教师页面外层保留统一导航，右侧独立内容 frame 加载原业务页面；原业务脚本与样式留在各自文档中，避免互相污染。
- 普通教师页面请求返回外壳，`Sec-Fetch-Dest: iframe` 请求返回对应业务页。学生 `/join`、`/s/*`、数据接口、文件导出仍沿用原路由，教师访问限制在外壳路由之前执行。
- 侧栏及业务页普通内部链接切换主内容；下载、外站、另开页面链接保留原行为。
- 地址栏同步业务路径、查询和哈希，支持深链接与前进后退。业务页内 `replaceState/pushState` 同步外层地址。
- 保留评分标准、成绩复核、作业录分的未保存/进行中离开保护。
- 窄屏使用顶部功能选择器，无嵌套侧栏。

验证：

- `tools/check-workspace-navigation.js`：内容导航、活动状态、query/hash、后退、离开保护、下载/外链通过。
- 批改上下文、复核工作台、作业页面回归与语法检查通过。
- 浏览器假数据服务中，对比作业列表与自动批改：侧栏各项高度及边距完全一致，六个子菜单均约32px高、上边距0。
- 切换后外层地址变化、iframe原始src属性仍保留首次地址，业务标题更新，确认外层文档没有重新加载。
- 浏览器后退到作业列表、前进回自动批改正常；修改总分后点击侧栏被阻止，输入99保留，随后撤销未保存修改。没有提交假分数到真实数据。
- 390px顶部功能导航可切换签到管理，无页面横向溢出；临时视口已重置。
- 正式服务以既有仅本机模式恢复；本次不改变局域网开放范围、不运行WorkBuddy。
