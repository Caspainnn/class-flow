# 签到流程优化（2026-10-27）

- 开始按钮简化为“开始签到”。
- 扫码签到仅显示题目和普通选项，不显示正确标记，不显示“只在老师屏幕显示”。
- 结束接口在归档后返回最终题目与统计快照，页面进入第三步“结束归档”。
- 第三步展示正确答案（兼容单选、多选）、各选项人数、签到人数与正确率；无人答题时正确率显示破折号。
- 可查看签到记录或再出一道题；新出题前刷新最近题目数据。
- 防重复结束提交，忽略结束期间或离开扫码阶段后到达的轮询结果。
- 修正签到倒计时的毫秒与秒混用问题。
- `tools/check-session-flow.js` 与 `tools/check-session-multiple-api.js` 通过。
- 浏览器以假数据走通新建多选题 → 扫码阶段不显示答案 → 结束显示 A、C → 再出题。没有提交或归档真实课堂数据。
- 正式服务保留局域网扫码配置。
