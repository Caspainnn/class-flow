# 课件中断续做

用户在逐页生成PPT中断后可选择：从已完成页继续，或全部重新生成。仅适用于初次逐页HTML制作；大纲生成和PPTX导出仍按整轮重试。

## 行为

失败/取消页面自动检查本轮可复用进度，显示“已完成X/Y页”和“从第X+1页继续生成”；全部页面已写完时改为收集成品，无需再次调用模型。另保留“全部重新生成”。用户自主选择，不自动续做、不自动消费额度。

每页校验静态HTML、标题、完整讲稿和备注后保存ready.json检查点，包含最终HTML哈希与完整元数据。续做只复用从第1页开始连续通过检查的页面，遇到缺失、损坏、不完整或哈希不符即停止复用；不会跳过坏页拼接后续页面。既有中断记录没有ready文件时，也可逐页校验后复用，原稿图片会在内存中安全内嵌。

教学要求版本、大纲完整内容、模板SHA和输入要求须与中断轮一致。修改任何相关输入后拒绝复用；前端说明原因，用户可全部重新生成。请求携带resumeRunId，服务端检查最新轮次、防重复和任务忙碌。页面缓存复制到新运行目录，原记录不覆盖；已完成图片、署名、备注与讲稿保持不变，已经复用的外部图片不重新检索。只有全套完成后才发布新HTML版本。取消续做同样保留新目录中已完成页，之后可继续。

## 验证

check-ppt-resume.cjs：3页虚构任务完成2页后失败，只调用模型替身生成剩余页；损坏检查点拒绝复用；错误轮次拒绝；续做再次取消后还能续做；首2页HTML、讲稿/备注、外部配图及署名不变，配图仅检索一次；旧目录保持不变；全部重新生成从第1页调用。check-ppt-html-flow、update-integration、new-task及source-images回归通过。独立代码复核未发现重要问题。

实际5页失败任务只读检查发现前4页通过本地校验，能够从第5页继续。本轮未调用真实模型、未替教师启动续做；原生浏览器按钮操作尚待用户验收。
