# 模板布局说明书上传选项

2026-11-03：补齐此前确认但漏做的上传选项。上一轮仅集成大纲布局展示与选择，本轮接入模板说明书。

- 入口：`http://127.0.0.1:3000/preparation?type=ppt&section=templates#upload`。在“模板文件与信息”的模板简介下，默认勾选“使用 WorkBuddy 编写模板布局说明书”。
- 勾选：先保存模板、程序识别并生成原页预览，再通过现有本机 CLI 连接调用 WorkBuddy。分析所有程序布局及首尾页的实际预览，生成用途、估计内容容量、使用限制；结果逐项校验布局编号后保存。
- 取消勾选：沿用原程序识别与确认流程，不调用说明书模型。旧接口省略选项也不自动调用模型；旧模板不自动产生分析任务。
- 说明书在模板详情中可展开查看。连接未配置、交付无效、超时或服务中断时，保留模板，局部显示原因并提供重试。相同模板同一时间仅分析一次；已完成的同源说明书复用缓存。
- 确认布局时按原布局或原页继承说明书，新任务选择模板时保存说明书快照。大纲生成读取用途、容量、限制，遵守教师固定页数或旧课件保留要求；自动页数可据内容拆合，不为变化而使用不合适布局。更新旧课件的轻量布局索引也包含说明书。
- 模板后续分析、删除或关闭说明书，不改写已保存课件快照。未启用时模板详情维持原样。上传组件、布局确认、首尾页与其他流程沿用原实现。
