# 大纲教学目标展示修正

## 原因与规则

旧课件更新大纲的 `objective` 由更新提示词定义为“保留内容与更新范围”，界面却将其统一标成“教学目标”，导致制作要求暴露在目标区域。

教学目标使用独立的 `teachingObjective` 字段，只写学生学完能做什么。更新模式仅提取原稿明确存在的目标，没有就留空；新建模式也允许留空，禁止用制作指令补位。查看与编辑界面均省略空目标区域，只保留逐页大纲。

兼容历史数据：旧更新大纲的 `objective` 保留作内部制作上下文，不在界面展示；旧新建大纲按原有约定将 `objective` 作为教学目标。明确的 `teachingObjective`（包括空字符串）优先于历史字段。编辑与保存保留内部说明和原稿来源映射，无需重生成已有大纲。

## 验证与验收

运行 `node tools/check-ppt-teaching-objective.cjs`，覆盖历史更新指令隐藏、真实目标展示、空目标省略、转义及编辑保存往返；测试使用独立数据，不调用模型或修改真实任务。

本机回归通过：教学目标、大纲编辑、逐页大纲、返回与取消编辑、首尾页布局以及更新模式集成。已在当前真实任务网页只读验证：查看和编辑均无目标区域，逐页内容保留；无目标时编辑焦点转到第一页标题，无脚本错误，未保存或重生成真实任务。
