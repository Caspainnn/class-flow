# 大纲布局选择正式集成

2026-11-03 用户验收独立网页原型后授权集成。本次范围是正式逐页大纲中的布局展示、更换与编辑保存；遗漏的 WorkBuddy 模板说明书及上传选项已在[后续补齐记录](2026-11-03-模板布局说明书选项.md)中实现。

## 行为与数据

- 入口：`http://127.0.0.1:3000/preparation?type=ppt`，进入已有课件的“生成大纲”。无需独立端口，原型路由继续保留。
- 每页右侧展示任务中已确认模板快照的真实区域几何、布局名称与更换入口，复用模板确认页面已有的结构图函数。只显示区域类型，不复制模板旧正文。无模板时省略布局区域；未知布局提示重新选择，旧布局缺少形状时仍能打开。
- 更换布局弹窗展示当前模板候选和所选布局放大图、实际来源页；不伪造说明书、选择理由或容量说明，不展示“结构示意 · 非最终页面”。
- 查看状态“应用布局”通过现有 `PUT /api/ppt/tasks/:id/outline` 保存；成功后刷新布局，失败留在弹窗并保留选择，支持重试。
- 每页“编辑大纲”定位到该页的正式编辑表单，保留现有增删、排序、时间及来源页码编辑。编辑中的布局应用只更新草稿和对应缩略图，随“保存大纲”统一提交；不会重建整份表单，因此保留已输入内容。
- 未应用时返回或 Escape 只关闭选择器，并恢复到触发按钮；请求提交期间禁止重复操作及 Escape。未保存大纲的取消沿用现有放弃确认。
- 首尾页显示制作时实际采用的专用布局，提供查看入口；普通页面仅能选择已确认的普通布局。增删或移动页面后重置不适用于新位置的角色布局，按新首尾位置重新绑定，避免保存时出现角色布局校验错误。单页课件沿用封面规则。
- 保存布局会沿用现有服务规则清除课件检查和 HTML 确认标记，回到待确认大纲；已有版本保留。仍需点击“确认全部页面，生成PPT”才启动制作。
- 教学目标为空时继续省略，更新旧课件的内部制作要求仍隐藏。
