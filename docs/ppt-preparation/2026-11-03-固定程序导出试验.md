用户授权：先将当前项目备份到 `Caspainnn/class-flow`，再尝试以固定程序处理常规转换，AI 只用于少量不能直接转换的部分。

- 试验分支：`codex/deterministic-ppt-export`；不替换正式平台导出链路，不干预原任务。

## 原因与方案

原链路要求模型将已确认 HTML 重新编写为 SVG 再运行 PPT skill。问题样本的执行跟踪显示大量读取转换库源码、反复推理，尚未进入实际转换。因此本轮不再让模型重新编写常规页面，而由浏览器测量现有 HTML 的排版，使用 python-pptx 写出文字、图形和图片。

试验入口及限制见 [tools/experimental/README.md](../../tools/experimental/README.md)。这是技术试验，尚未作为任意 HTML 的通用转换器。

## 本机验证结果（待用户检查）

| 项目 | 结果 |
|---|---|
| 样本 | 已确认的 5 页 HTML，只读，不改内容 |
| 最终完整导出 | 4,503 毫秒，不含 PowerPoint 人工/截图审查 |
| 原生文字 | 249 个可编辑文字片段，和抽取场景逐页比对一致 |
| 常规原生图形 | 136 个矩形、圆角块、边线等 |
| 图片 | 1 张原有图片，4 个 SVG 图示局部截图 |
| 讲稿 | 对应 5 页的完整讲稿均写入备注，原文比对通过 |
| 视觉 | 使用 PowerPoint 渲染逐页对比；主要布局保留，已去除默认主题附加阴影 |
| 逐页保存 | 每完成一页替换检查点 PPTX，记录完成页数与阶段 |
| AI 调用 | 0 次 |

限制：SVG 图示内部暂不可编辑；文字框按浏览器行片段拆分；简单渐变近似、CSS 阴影省略，尚未覆盖任意 CSS 层叠、旋转和裁剪。旧 HTML 原有的重复信息、页眉和来源标记会原样保留，这属于内容生成规范，不由导出器擅自修改。

后续正式接入范围：扩充视觉样本，验证长课件和复杂图示；与现有任务状态、取消、超时、版本收录和部署依赖集成；对确实不能直接转换的少量图形再考虑 AI 补偿。未经这些验证，不将单份样本成功等同于正式功能完成。
