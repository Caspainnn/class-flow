# 配图意图与自动检索

用户已确认：逐页大纲展示配图主题和用途，制作时找图并匹配布局，实际图片在PPT预览中检查；整套最多一张外部照片/插画，原生流程图、概念图和数据图不计入。没有教学价值时零配图。

实施顺序：大纲结构及编辑 → 平台 Commons 检索与受限下载 → 图片布局及逐页HTML嵌入 → 预览更换/取消并保留历史 → 隔离验证。大纲审阅不请求图库、不下载图片。模板优先匹配有效图片占位区域；同等候选随机一次并保存。没有图片布局时采用明确的右图左文区域，沿用模板视觉。

图片源先接 Wikimedia Commons API。只发送教师已确认的检索关键词，不发送附件。仅接受明确的 Public domain、CC0 或 CC BY，保存作者、许可和来源。未找到、下载超时或图库不可用时标记未配图，继续制作，预览中保留原因。下载限定官方域名、禁跳转、限时限大小、校验PNG/JPEG签名，嵌入静态HTML，不加载远程资源。图库元数据为不可信数据，先转换纯文本，不作为模型指令。

更换或取消配图保存新的HTML版本，版本冲突时拒绝覆盖；修改期间锁定本课件，旧课件和讲稿保留。换图保持原区域，不重新调用模型；改变正文排版仍使用现有“提出修改要求”。

依据：[Commons API](https://commons.wikimedia.org/wiki/Commons:API/MediaWiki)、[元数据说明](https://commons.wikimedia.org/wiki/Commons:Machine-readable_data)、[复用说明](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)。图库元数据不保证内容相关性和权利状态绝对正确，实际图片需教师在成品预览中核对。

使用：在现有或新生成的逐页大纲点“调整大纲”，仅给需要图片的一页选择“制作时网上找图”，填图片内容和教学用途（检索关键词可选，默认使用图片内容），保存后整体确认生成PPT。课件预览侧边显示该页配图来源和操作；“换一张”“取消配图”保存新版本。未配到图片时显示原因，改变配图意图可返回大纲重新制作；本轮不会自动重跑用户已有任务。
