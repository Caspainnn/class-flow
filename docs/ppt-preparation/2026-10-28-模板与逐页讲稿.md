# PPT模板与逐页讲稿

教师流程保持四步：填写要求 → 选择方式 → 生成大纲 → 生成PPT。导出可编辑PPT仍为按钮，不增加流程步骤。

## 使用

填写要求时，可从本机模板库选择PPTX，或通过Element Plus拖拽/点击上传。一份不超过20MB，重复内容自动复用，同一库最多100份。模板与参考资料分开，避免把旧课内容当作新要求；选用模板会保存任务快照。模板变更使现有课件审批失效，保留教学大纲与旧版本。

用户提供的36页授课版已真实验证并加入正式模板库。制作工具收到原件及平台提取的字体、配色、画布和版式信息，作为视觉参考；新课内容按教师要求重新编写。当前并不承诺逐像素复刻模板原件的图片、母版和所有装饰。

大纲确认后先生成页计划，再按顺序为每页启动独立制作进程。一页的静态页面、教师备注和完整口语讲稿均校验通过，才启动下一页；两小时上限覆盖整个本轮。页面显示真实的当前页/总页数与完成页数。没有完整交付时不发布伪课件；取消不会启动后续页。

生成PPT后逐页可看演讲稿，并下载完整Markdown讲稿，按页码和标题排列，含[提问]等教师提示。讲稿与课件版本绑定；指定页修改时同步改写该页讲稿，其余页正文、标题、备注与讲稿均须保持不变。导出时将讲稿一并交给工具写入PPT备注，独立讲稿下载仍保留。旧版本没有讲稿时明确提示，不补造。

## 开发验证

`node tools/check-ppt-template-pages.cjs` 覆盖模板验证/去重/任务复用、真实串行进程顺序、讲稿缺失拒收、不可变历史、单页修改边界、取消停止后续页。HTTP检查覆盖模板上传、列表、选择、下载及坏文件拒绝；旧PPT流程与教案核心回归均通过。

浏览器本地文件选择受扩展“文件URL访问”权限阻止，未改浏览器权限；提供的原件通过平台本地接口导入，再在教师界面实际选择。普通点击/拖入共用真实Element Upload处理，组件单元及本地接口已验证；未把此权限受阻的浏览器上传记为通过。

真实模型验证使用隔离3018平台、20分钟“认识三角形”三页虚构内容，先在平台填写要求和选择所给模板，再点击生成大纲、确认后逐页制作。运行数据位于 `.tmp-ppt-template-review`，不混入真实教学任务。后续结果另记实测记录。

正式启用前确认没有进行中的签到、批改、PPT及教案任务；启用后79份既有数据哈希不变。正式入口 `http://127.0.0.1:3000/preparation?type=ppt`，仍待用户验收。
