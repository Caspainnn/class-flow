# 本机固定程序导出接入

当前范围：平台自动制作仍由 WorkBuddy 生成大纲、HTML 和讲稿；老师确认后，“导出可编辑PPT”改由固定程序读取同一版 HTML，不再让模型重新制作 SVG。不影响手动外部交接、旧版本和原稿。

## 使用与部署

- 已有 HTML 可直接导出，无须重新生成大纲和 HTML。已经导出同版文件时沿用原有下载入口。
- 需要 Node 20+、本机 Chrome/Edge，以及配置 Python 中的 `python-pptx`、`Pillow`。优先使用 `ppt.pythonPath`；浏览器自动查找常用安装目录，可用 `ppt.browserPath` 指定。依赖未就绪时保留课件，显示本机导出问题，不自动改用模型。
- 沿用导出阶段、后台完成/失败通知、红框取消确认、版本与 HTML hash 绑定、完整讲稿校验。进度区区分“读取排版”和“导出完成页数”，每页保存检查点。
- 文字和常规色块、边线为原生对象；SVG 图示内部暂不可编辑。讲稿和原有教师备注、图片完整出处写入对应页备注。下载名为课程主题。
- 独立浏览器配置，仅渲染已通过静态校验的内嵌页面，禁止 HTTP/HTTPS/file 等外部资源请求。取消或超时终止本轮进程树，不发布迟到成品。

## 已知边界

当前覆盖常用 1280×720 HTML 排版，不保证任意 CSS 保真。简单渐变近似，CSS 阴影省略，文本按浏览器行片段拆成文本框。暂不支持的背景图片、复杂自动编号及跨容器层级会给出错误，避免静默遗漏内容；老师可修改当前课件后再导出。不会擅自重写已确认内容、页眉或页脚。

## 本机自测

| 检查 | 结果 |
|---|---|
| 无 CLI 配置仍可导出、明确确认当前 HTML | 隔离服务测试通过 |
| 失败保留旧文件、取消不收录迟到文件、进度与版本绑定 | 隔离服务测试通过 |
| 图片 contain 比例、显式/自动层级前景、完整备注出处 | 真实浏览器/Python 合成样本通过 |
| 已有 5 页 HTML | 完整服务路径约 7–8 秒，不调用模型；页数、文字和逐页讲稿校验通过 |
| 50 页虚构课件 | 完整服务路径约 12–15 秒；逐页文字和讲稿通过（不代表复杂 50 页视觉压力测试完成） |
| 原有 HTML 编辑、当前版本约束与 HTTP 下载 | 回归通过 |

验收状态：待用户验收；本机测量不构成任意课件的耗时承诺。

本机服务已在检查所有模块均无后台任务后重新加载，3000 端口 `/api/ppt/connection` 返回 `exportReady: true`。已有 HTML 无需重做即可点击导出。浏览器界面自动化工具本轮初始化失败，因此按钮状态通过前端渲染测试，真实转换通过隔离服务与 HTTP 下载回归验证；未将其写成实际人工点击验收通过。

可复跑：`node tools/check-ppt-local-export.cjs`；`node tools/check-ppt-native-export.cjs --geometry`；`node tools/check-ppt-native-export.cjs`（默认50页合成内容，仅写隔离目录）。
