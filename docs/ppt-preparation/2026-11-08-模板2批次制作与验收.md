# 模板 2 批次制作与验收

- 原稿提供教学内容和逐页映射。选定模板提供封面、正文和结束页的布局、配色、字体层级及装饰。保留讲解所需的图、表、公式、代码、关键数据及标签。原稿的页边框、彩条、母版底纹、讲台剪贴画及结尾礼仪人物属于旧装饰，使用模板视觉替换或省略。遇到用途不明的图片，先结合正文和原稿图注判断。
- 有确认模板时，先并排查看模板封面截图和实际渲染的 HTML 首屏。核对主标题位置、字号层级、分栏比例、配色、装饰线和授课信息区。发现旧校徽横幅、旧背景或旧布局仍占主画面，修订后再批准导出。
- 正文和结尾逐页检查是否混入原稿装饰。模板 2 封面采用深蓝左栏、短黄色装饰线、右侧蓝色标题区和浅蓝授课信息卡。模板中的示例课程文字、受众、日期均省略或按本课已确认信息替换。
- 实际 PPTX 检查页数、映射、授课人、日期、同级标题中英数字及标点的字体槽和字重。用 PowerPoint 渲染全部页面，放大检查图表标签、裁切、越界、重影和遮挡。返工后重新导出和复验，再更新交付文件。
- 首份反馈涉及第 1 页误沿用原稿封面，以及第 3、10、12、16、18、21 页误保留原稿装饰插图。后续课件按上述检查点执行。

## 独立审核与交付

- 每次派审固定到一个平台导出版本。随附任务 ID、PPTX、模板 2、原稿、实际 HTML 封面截图及 PowerPoint 全页渲染目录的绝对路径。返工产生新版本，旧版留作追溯。
- 审核对话只读，逐页给出通过、退回或待补证，并写明证据与复验条件。主对话负责修订、重导和复审。
- 派审后可提前制作一份。上一份待审时，下一份最多推进到已导出待审。发生模板、字体或导出共性问题，先修正规则并检查在制版本。
- 交付清单区分已交付、待审、待返工和未制作。派审启用前的成品标注为主对话已验收。启用后，只交付独立审核通过的确切版本。
