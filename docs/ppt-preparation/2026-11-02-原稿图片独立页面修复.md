# 原稿图片引用导致独立页面校验失败

实际失败位于第4页，img.src=../../source-reference/media-5.png。该图属于本页映射的原稿第10–12页的已提取媒体，并非网上资源；模型选择本地路径引用，平台缺少转为内嵌资源的处理，独立HTML校验按预期拒绝了它。前端将“HTML课件”替换为“课件课件”，造成重复文案。

修复：新增source-images.js，根据本页sourcePages对应detailsFile.media建立白名单，将img.src及SVG image.href中的已授权原稿媒体路径替换为data URI。只修改原HTML中对应属性的源码范围，不重新序列化整页，保持文本、样式与其他属性不变。只允许run目录内已提取的media-N图像，不读取其他本地文件；外部网络链接、未知路径和未授权页图片仍交由原静态HTML规则拒绝。逐页生成与逐页修改收集均执行此处理，普通新建流程不变；更新提示词说明原稿媒体可以由平台内嵌。

验证：实际失败页只读内存回放，7001字节HTML内嵌后2602913字节，独立页面校验通过，未覆盖正式失败产物或重新调用模型。check-ppt-source-images.cjs覆盖原稿图片相对路径/编码路径、普通文本原样保留、外部网址/未知文件/未授权媒体拒绝、已有data URI不变及重复文案。update-integration以相对路径交付原图验证逐页链路，HTML流程和预览回归通过。尚未重新跑模型完成整套课件。
