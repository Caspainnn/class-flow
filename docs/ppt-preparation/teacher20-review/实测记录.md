# 20分钟教师流程实测

日期：2026-10-28。用户授权实际制作测试并模拟教师操作。虚构主题为小学三年级“认识三角形”，20分钟、6页，不关联真实课程。隔离平台使用3012端口，数据位于被Git忽略的`.tmp-ppt-teacher20/data`，沿用原账号及固定PPT Master，未使用宽泛Shell授权。

浏览器工具开始时初始化失败，因此创建任务、真实大纲生成和第一次大纲调整先通过平台业务接口完成；工具更新后恢复，后续通过Edge实际界面操作。不将接口测试冒充界面测试。

## 已取得的实测证据

- 实际大纲6环节，教师将导入从2分钟改为1分钟、练习从5分钟改为6分钟，合计仍为20分钟。
- 第一次HTML轮次遇到模型服务`empty_model_response`，约15分钟后结束，没有产物。现已修复诊断，页面明确提示模型空响应，保留原大纲。
- 浏览器点击“重新发起”后，模型真实生成6份HTML并交付。教师逐页点击、检查定义、例子、练习答案与备注。成功轮次约3分钟，具体耗时以任务落盘时间为准。
- 活动列表实际展开后，跨轮询保持展开；截图见`progress.jpg`。
- 补充UI表单检查：点击新建，填写虚构主题、对象、20分钟与内容，保存进入制作方式选择；选择平台调用并返回上一步，DOM输入值仍为20。该草稿未启动模型。
- 初次与新版本返回时两次出现预览空白，切页后恢复；已改为先获取服务端校验的真实HTML，再装入无脚本sandbox的srcdoc，同时内置限制资源的CSP和加载/失败状态。重开任务后首屏直接显示实际HTML，第二页切换正常；未放宽iframe执行权限。真实封面截图见`html-cover.jpg`。
- 第2页存在图形底部“边”标注裁切；教师已在行内输入框提交单页排版修改。一次模型只回复计划而未写文件，现补充明确交付提示，页面改为说明“工具已结束但未交付HTML”，不再笼统显示文件不存在。
- 教师取消长时间无新活动的修改轮次：确认弹窗默认焦点为“继续等待”，确认取消后原HTML版本保留。随后仅在隔离配置中测试CLI支持的`reasoningEffort=low`，不更改正式配置。

## 最终结果

HTML第2版真实交付；仅第2页哈希变化，其余5页HTML及全部备注完全保留。第二页标注裁切已通过平台中的修改要求修正，截图见`html-revised.jpg`。教师明确勾选并确认第2版，随后才启动PPTX转换。

第一次转换报告命令权限受限，未交付文件；由于旧日志只保留末尾32K，具体失败命令已无法完整还原，不把模型总结当成完整命令审计。扩大有界日志至256K字符，补充只使用已放行Python单条命令的交接要求，禁止cd/串联Shell/pip等非必要命令。重试保持`allowShell=false`与原模型，成功记录包含`python ...project_manager.py`、`text_measure.py`、`svg_quality_checker.py`、`svg_to_pptx.py`等实际调用，未扩大任意Shell权限。

实际PPTX为6页，40,110字节；浏览器点击“下载可编辑PPTX”取得文件，与平台发布版本逐字节一致。成品归档为`20min-triangles.pptx`，SHA256：`a1902cb2dedd10a254975a4a44c284c3e09ea4d93bd114204e8d2478ee2a5a5a`。绑定HTML版本2。

PPTX结构检查：各页原生文字长度128/125/130/137/186/152；各页备注长度94/106/124/65/119/116。已通过实际PowerPoint打开，无修复弹窗；编辑视图暴露独立文本框、形状及组合对象，实际看到课件呈现、缩略图和备注。未执行改字保存测试；原生对象结构验证不等同于每个元素都经过修改测试。

随后通过平台勾选检查并点击“标记可上课”，隔离任务最终状态`ready`，复核版本1；截图见`ready.jpg`。正式教学数据未用于测试，原75份数据文件SHA256变化0份。

## 实际耗时与限制

成功轮次：大纲约28秒；HTML首版155秒（2分35秒）；单页修改579秒（9分39秒）；PPTX转换711秒（11分51秒）。另有一次约15分钟的模型空响应、仅回复计划、被取消的无新活动轮次和一次受限命令失败，不能只用成功轮次时间宣称全流程已经足够快。未计人工阅读、排查和中断等待。

15项相关回归与PPT模块语法检查通过。空响应诊断、交付缺失提示、HTML首屏装载和有界日志修订已进入本轮代码；单次`reasoningEffort=low`只在测试配置启用。不能从这一个样例推断低推理强度一定更快；正式设置仍保留原值。

模型响应时间不等于演说课时；20分钟输入限制本次教学内容量，不修改两小时运行上限。
