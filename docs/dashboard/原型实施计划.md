# 数据看板原型实施计划

依据：[规划](规划.md)，用户于2026-11-01授权开始原型。

目标：提供可交互的教师端数据看板原型，不接触正式数据、不替换正式导航。
技术：原生HTML/CSS/JavaScript、内联SVG、Node静态预览服务，无新增依赖。

- [x] 创建`prototype/dashboard.html`、`dashboard.css`、`dashboard.js`：侧栏数据看板位于工作台下，五个页签，示例课程/时间筛选、图表、明细抽屉、空态与局部失败演示。
- [x] 创建`tools/preview-dashboard.cjs`：仅本机GET/HEAD白名单静态资源，默认3014，不开放业务写接口。
- [x] 校验脚本语法、示例数据聚合口径、页面资源与桌面/窄屏展示，记录验收入口。

全局约束：原型显著标注示例数据；比例为分子分母加权；匿名问卷无未交名单；未录分不自动视为未交；当前存量与所选期间数据分开说明；不上线、不提交无关变更。

重点复核：零分母、课程/日期切换、未关联资源、任务失败但有历史产物、抽屉关闭及键盘、页签布局稳定。
