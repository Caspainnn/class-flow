# 数据看板正式交付与验收

2026-11-01。实施完成，自测通过；用户正式验收待完成。

入口：`http://127.0.0.1:3000/dashboard`，侧栏位于工作台下方，移动端功能导航同步增加。

## 已集成内容

- 采用已验收的单页紧凑原型，六项指标与课堂趋势、待办、作业批改、问卷、课程概况、备课资源同时展示。
- 数据来自当前DATA_DIR，页面不加载原型文件或固定示例数据。独立构建脚本`tools/build-dashboard-public.py`仅在开发时复用原型视觉，运行时不依赖prototype。
- 课程、学期、近7天/30天/全部/自定义自然日筛选；筛选互相影响，全部日期以Asia/Shanghai计。期间内没有数据时显示空态，零分母为“—”。
- 课堂按当前名单有效studentId去重，按日汇总人次后计算比例；进行中签到单列待办；已结束空记录不推断全班缺勤，不进入比例。原始答卷、姓名和学号不返回看板接口。
- 作业统计按创建时间筛选，关联文件批次不重复计数；区分未录分、明确未交、待匹配和异常。均分只取有效成绩，旧批改满分换算与作业模块保持一致。
- 问卷期间答卷按submittedAt独立筛选，不要求问卷在期间发布；实名用发布名单target快照、按学生去重；匿名只按份数；总回收、期间回收分开显示，归档保留历史答卷。
- PPT/教案期间产物按全部版本的createdAt筛选，以任务计数，避免多版本重复算课件。当前运行状态与已有历史产物并存。模板为全局当前库存；PPT布局数只计已确认布局；教案内置模板单列计入库存。
- 任务待办不随活动日期截断，受课程/学期筛选约束；未关联备课与问卷生成任务仅全平台展示。点击进入现有制作任务、问卷结果、作业详情或对应批改批次，不在看板执行写操作。
- 删除课程、作业、模板和课件均按现有软删除字段排除。当前关注人次复用旧规则阈值与历史最大连续缺勤等语义；不创造学习能力分。
- 自动每60秒刷新可见看板，切回可见时刷新；防旧请求覆盖新筛选；失败保留最后成功数据与更新时间，不以0伪装请求失败。

## 旧看板迁移

移除“学情分析 → 数据看板”的侧栏项和页面页签，学情主入口进入预警；预警名单、个体画像、练习分析与问卷管理保留。`/xueqing?tab=dash`重定向到`/dashboard`，保留courseId。工作台原看板快捷入口同步指向新入口。旧学情页面的隐藏统计函数暂保留供既有渲染依赖使用，用户无法再从页签进入旧看板。

## 口径限制

历史签到没有名单快照，按当前名单重算；当前规则中“作业未交”可能由缺成绩触发，新看板只称规则关注，不宣称已经核实未交。缺少完整历次运行终态和登录探活，不展示制作成功率、节省时间或模型实时在线结论。看板只读适配持久化文件，不创建会修正运行状态的生成服务实例。存储损坏时整个统计响应返回可重试错误，避免部分数字悄悄变0。

现阶段页面是教师私有统计页，不作为公开投影模式；模板预览和课件编辑仍由原业务模块处理。
