# 数据看板正式集成

2026-11-01 用户授权集成，沿用已验收的单页紧凑布局。原型为视觉依据，正式版不带示例数据。

1. `server/dashboard/service.js`：只读聚合课程、名单、签到、作业/批次、问卷、备课任务与模板；按课程、学期、日期过滤。持久化文件适配器只读，不实例化会修正运行状态的生成服务；不调用模型。数据损坏返回可重试错误，不静默用0替代。
2. `server/dashboard/routes.js`及`public/`：教师本机API与正式单页，复用原型图形样式，异步加载/刷新防旧请求覆盖，明细回到已有业务页。无固定示例数字、图表或名单。
3. 导航：工作台下加入`/dashboard`；移除学情旧看板页签和侧栏子入口；旧dash链接跳转新看板并保留课程。学情主入口默认预警，其他模块保持。
4. 隔离数据检查：加权比例、未录分与明确未交、名单去重、实名快照/匿名、日期独立、软删除、未关联资源、任务失败保留产物、零分母、教师权限与旧路由；正式读操作只核查可用性，不修改教学数据。

日期统计使用Asia/Shanghai自然日。存量、当前任务与关注规则不随活动日期变更，期间答卷按提交时间独立过滤，不以问卷发布日期代替。缺历史名单快照明确标注。预警复用现有阈值及算法，缺成绩不在看板另标为确实未交。签退/正在运行的任务不得因集成测试而中断。

状态：实施完成；隔离统计、HTTP、页面脚本测试通过。正式服务已加载，浏览器已验证课程筛选、作业明细直达、侧栏位置及返回看板；用户正式验收待完成。详见[正式交付与验收](正式交付与验收.md)。
