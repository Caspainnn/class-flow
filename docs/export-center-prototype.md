# 导出中心原型

状态：已取消。导出功能保留在签到记录、作业成绩、学情分析各业务页面。以下为历史设计记录，不作为实施计划。原型归档于 `docs/archive/export-center-prototype.html`。

定位：统一老师交付表格的入口，避免分别去签到、作业与学情页面查找导出按钮。保留业务页快捷导出；中心承担跨记录选择、字段配置、预览及再次下载。

结构：选择课程与学期 → 选择导出类型 → 勾选记录与字段 → 预览 → 生成 → 最近导出。

三种内容：

- 签到记录：支持单次或多次，明细按签到批次合并；可选答题内容与正确答案。
- 作业成绩：选择一份或多份作业，每份作业一个工作表，可选逐题成绩、给分依据、总评及复核状态。待复核作业允许选，但需保留状态并在确认时提示。
- 课程汇总：学生一行，呈现出勤、作业提交与平均成绩；不引入未经老师配置的总成绩权重。

第一版统一 XLSX，不先扩展 PDF、图表报告、定时导出与复杂模板编辑。最近导出展示已生成文件及配置，复用配置时读取当下数据重新生成，避免误以为历史文件会自动更新。

已有能力：签到 Excel、作业 Excel、学情分析 Excel。正式开发时复用已有导出逻辑，新增统一筛选和字段配置、文件记录管理，不在原型阶段改动正式导航。

原型文件：`prototype/export-center.html`，使用虚构示例数据。类型、课程、学期、记录与字段勾选、空态、确认弹窗、模拟生成及配置复用可交互。没有接入真实数据或实际下载文件。

验证：浏览器已走通字段取消后更新预览、确认模拟生成、切换签到类型、空选禁用生成、复用历史配置。1440px为配置与预览双栏，390px为单栏且无页面横向溢出。正式评分页多余的右花括号同时修复，页面语法与复核行为检查通过。
