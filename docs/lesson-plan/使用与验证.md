## 使用方法

侧栏“课前 → 教案制作”（`/preparation?type=plan`），点击“新建教案”。

1. **填写要求**：主题、授课对象、本次总分钟数（5—240整数）、教学内容。可不关联课程；有参考资料时教学内容可留空。点击“保存草稿”后可稍后继续。
2. **选择模板**：使用内置九章教学设计，或上传DOCX加入本机模板库。上传的模板可在其他任务复用、下载原件。点击“使用此模板，准备生成”才应用选择。
3. **生成教案**：点击“开始生成教案”，由已连接的WorkBuddy真实生成，使用模型额度，最多等待两小时。可返回列表；重新打开能继续查看。失败原因留在任务内，可重试。停止需要红框按钮和明确确认；要求、资料和旧版均保留。
4. **编辑与下载**：逐节编辑文本、活动、表格；教学过程时间必须合计为要求分钟数。保存生成新版Word，下载链接明确对应已保存版本。历史版本只读，可下载；相同要求和模板下可恢复为新版本。修改要求、附件、模板后旧版保留但标为旧要求，须重新生成。

课后“实际记录”在模型生成时强制留空，只允许教师据实填写。未知教师、地点、教材范围不编造。模板基本信息字段与教师填写区不能删掉；可在右侧填内容。

参考资料复用本机Element Plus Upload，支持点击与拖拽，每份20MB、最多12份，支持PDF、DOCX、PPTX、TXT、MD、PNG、JPEG。Word/PPTX正文和备注提取为文字供模型阅读，图片/版式不作复刻。扫描PDF和图片依赖模型识别，教师需核对。上传资料会交给当前WorkBuddy模型，请勿提供学生隐私资料。

## 模板范围与本机存储

用户提供的《第03学时_GAN生成sin曲线实践_教学设计_模板版.docx》已实际读取并通过上传识别：九章、五类表格。内置模板按它的结构整理，未把45分钟、GAN样例内容或课后成效当成平台默认。

支持以“一、章节名”或Word一级标题组织的模板、普通行列表格和一张时间表（列名“时间”或“时长”，可带单位括号）。明确拒绝合并单元格、嵌套表格、无法识别的章节/时间结构。保留章节、表头、基本信息字段和填写区，Word重新排版，不承诺原件的图片、页眉页脚与像素一致。

任务保存于 `DATA_DIR/lesson-plan/<任务ID>/`，包含task.json、参考原件/提取文字、运行输入与受限日志、版本DOCX；模板原件与结构保存在 `DATA_DIR/lesson-plan/templates/`。随平台data目录整体备份，不提交Git。上传模板库上限100份。服务重启会将未完成生成标为中断，不假装成功，也不会自动重复扣用模型额度。

## 审查与修复记录

独立审查为只读评审，没有启动模型或修改服务。发现并修复：

- 压缩包伪报解压大小：改为逐块统计实际解压字节，提前停止；伪造目录大小用例由失败转通过。
- 上传期间可切换任务、保存期间继续输入：请求期间锁定编辑控件和页面内任务切换，上传捕获任务ID；保存原有disabled状态。
- 迟到轮询覆盖新任务：校验任务ID、步骤和页面代次；回归确认新任务不被旧响应替换。
- 移除附件后列表未同步：成功后重新挂载受控组件；保留尚未保存的要求输入。
- 空白结构可被当成交付：生成校验要求教学文字/表格内容非空，实际记录例外；没有合法文件不收录版本。

另修复标题误识别为第十章（用户原模板把文档标题也设为Heading1，优先使用中文编号章节），补充基本信息字段保留、深层XML限制及坏JPEG友好错误。真实生成内容自审后补全4+3退出题、答案7和六道作业，移除实现术语及未知章节编号。

## 正式启用边界

本轮新增服务路由需要重启Node进程，单纯刷新正式页面不足以启用。正式服务未动。启用前须核实无进行中的签到、PPT、批改和其他教案任务，核对正式监听PID、DATA_DIR和启动参数，再按现有启动方式重启并检查数据哈希。当前浏览器工具故障仍需恢复后补做教师操作与键盘验收；不能把本地自动检查写成用户已验收或正式已上线。
