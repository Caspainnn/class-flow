## 材料审核与方案

现有平台为 Node HTTP + 静态页面，教案入口为占位。可复用本机 Element Plus Upload、WorkBuddy CLI 配置和本机 JSZip；不修改 PPT 模块。用户 DOCX 已实际解包读取，含九部分和五类表格，时间是示例的45分钟，不作为平台默认课时。教学反思实际记录为空。参考 PPTX/讲稿可作为普通附件，不依赖 PPT 制作完成。

采用独立 `server/lesson-plan/` 模块、本地结构化 JSON、受限 CLI 文件读写生成、平台确定性导出原生 DOCX。相比让模型直接制作 Word，结构化结果可校验、可编辑且导出稳定；相比富文本编辑器，不新增依赖，也更容易保留表格。上传模板提取章节、段落与表头；保留结构与教师填写区，重新排版，不承诺原始模板的像素一致、合并单元格或图片复刻。原件保存在本机供下载。

## 教师流程

1. 填写要求：主题、对象、总分钟、内容；课程及补充要求可选。保存草稿后可继续。参考资料复用 Element Plus 点击/拖入，每份20MB、最多12份。
2. 选择模板：内置九章模板或上传 DOCX，查看结构；模板保存在本机供其他任务复用，选择后保存快照。模板必须有可识别时间列，避免看似支持却无法校验课时。
3. 生成教案：调用已连接 CLI，显示耗时、当前阶段、失败重试，风险取消使用红框和原生确认弹窗。不能通过CLI退出码推断成功，必须收到有效 JSON 并导出实际文件。
4. 编辑与下载：逐节修改文本、表格、增删教学环节；总课时必须等于要求。保存后生成新 DOCX 版本；历史只读预览、下载及恢复为新版本。修改要求/附件/模板后旧版仍保留并显示过期提醒。教学反思实际记录仅允许教师自行补充，模型生成强制留空。
