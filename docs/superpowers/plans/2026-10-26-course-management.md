# 课程管理正式实现计划

使用 writing-plans 制定计划，以 executing-plans 在当前工作区逐项执行。

**Goal:** 接入已批准的课程卡片、新建三步、单页管理、整区点击/拖拽上传及两个课前占位。
**Architecture:** 原生HTML/JS，复用已安装ExcelJS及名单接口；增加集中课程服务，保留旧入口兼容。无新依赖。
**Spec:** docs/ui-course-2026-10-26/design.md，以用户最新批准原型为准。

## 约束

- 保留现有未提交工作，不自动提交；真实data仅核对哈希，写入验证使用隔离DATA_DIR。
- 不调用模型，不修改WorkBuddy安装。预览服务仅监听127.0.0.1。
- 名单上传限制单个xlsx/csv、20MB，点击与拖入复用同一处理；保留错误行及输入。
- 创建时先保存基本信息取得课程ID，再导入名单；保存中锁定相关导航，防止异步串课。已创建课程返回列表后可继续维护。
- 删除课程采用关联软删除，保留名单/历史记录及原始文件；活动签到或运行中批改拒绝删除，页面二次确认。

## 任务

- [x] 集中课程服务与回归检查：统计、备注保存、软删除保留记录、运行保护、未知ID及旧课程缺省字段。
- [x] 正式课程HTML：移除示例数据，接通创建/保存/删除/名单导入、移除和搜索；错误保留，异步上下文保护。
- [x] 侧栏与旧入口衔接：课程管理、PPT制作、教案制作；旧admin课程入口跳转，保留课程定位。
- [x] 隔离API/浏览器验收、桌面/小屏截图、相关作业回归、真实数据哈希核对、文档同步。

## 审查重点

名单异步处理期间切换课程；重复学号和部分导入；网络失败后重试；删除课程不留下可见孤立作业；创建半途退出后不会重复创建。
