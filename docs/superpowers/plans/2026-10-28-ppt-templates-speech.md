# PPT 模板、逐页制作与讲稿

用户已授权实施。教师流程仍为填写要求、选择方式、生成大纲、生成PPT。

1. 模板是独立的本机可复用 PPTX 库。上传时验证真实包，提取实际字体、配色与版式信息；选用时保存任务快照。旧版本保留模板来源，不把模板旧课程正文当作新课内容。
2. 大纲确认后，先生成页计划，再逐页串行调用制作工具；一页的静态成品和口语讲稿校验通过后才开始下一页。整体仍受两小时限制，取消禁止启动后续页。实时显示当前页和已完成页数，不假造百分比。
3. 每页同时生成教师备注和口语演讲稿（含课堂提示）。讲稿与不可变课件版本绑定，可逐页查看和下载完整 Markdown。导出 PPTX 保留讲稿到备注，单页修改不改变其他页和讲稿。
4. 复用真实 Element Upload，模板仅接受 PPTX、20MB，参考资料默认行为不变。先隔离接口/假进程验证，再检查教师界面；不覆盖真实任务。

教案由用户要求的新对话独立实施，PPT 模块归本对话，公共文件采用局部修改。
