# 数据与备份：现状核查与改进规划

2026-11-01。阶段：规划待审阅，尚未修改业务代码、备份或恢复正式数据。

## 目标

让教师清楚知道数据是否已备份，能保存包含教学附件的完整备份，并在确认内容与后果后恢复。沿用侧栏“数据与备份”入口；建议改为独立页面，避免藏在系统设置末尾。旧`/admin?pane=set#data`保留兼容跳转。

本轮用户要求建立专用对话完善该模块；以下功能与顺序均为建议，尚未视为用户已批准实现。

## 已有实现及缺口

| 项目 | 已核查的现状 | 影响 |
| --- | --- | --- |
| 当前入口 | `server/public/shell.js`指向`/admin?pane=set#data`；`admin.html`的`#data`仅有路径与两条说明 | 没有备份记录、状态、创建备份或恢复入口 |
| 数据文件列表 | 旧课程设置区域有`loadDataInfo()`，调用`/api/data-info` | 只列第一层，目录使用`stat.size`，不能代表递归文件总容量 |
| 打开目录 | `/api/open-folder`通过Explorer打开DATA_DIR | 是文件夹入口，不是备份功能；无法判断是否已复制成功 |
| 现有导出 | 签到Excel、作业成绩、问卷CSV、PPT/Word文件等分散导出 | 用于查看/交付，不足以恢复完整平台 |
| 备份/恢复接口 | 所查服务与工具未发现全平台备份包或恢复协议 | 无格式版本、内容检查、恢复事务与回滚机制 |
| 存储方式 | `server/lib/store.js`按文件临时写入再rename；生成模块还有各自任务JSON与附件 | 单文件原子写并不等于全平台一致性快照 |
| 运行状态与缓存 | 服务持有签到状态、批改/制作子进程与内存缓存，部分任务get()会修正重启状态 | 运行中直接覆盖data风险高，恢复后必须重新加载服务与缓存 |
| 旧说明 | “所有数据在data里的JSON，一天几十KB”“拷走整个data就是完整备份” | 现已包含大量二进制附件；还不能据此承诺CLI、skill与登录态可迁移 |

代码依据：`server/server.js`的`/api/data-info`、`/api/open-folder`；`server/public/admin.html`的数据位置区域；`server/lib/store.js`；`server/lib/homework.js`；`server/grade/grade.js`；PPT、教案、问卷模块的routes/service。

## 备份应覆盖什么

| 数据 | 存储依据 | 建议处理 |
| --- | --- | --- |
| 课程、名单、签到记录 | DATA_DIR中的courses/students/sessions JSON | 完整保留关系与ID，包含软删除状态，不把备份当成业务筛选导出 |
| 作业、成绩、批改元数据 | homework/gradebatches JSON | 与批改原文件、结果一起备份；校验关联关系 |
| 批改原文件与交付 | DATA_DIR/批改/<batchId>，含final等 | 包含原始附件及有效交付；批次内的历史相对路径迁移时需检查 |
| PPT与模板 | DATA_DIR/ppt/<taskId>、ppt/_templates | 保留原附件、模板、确认布局、HTML/PPTX、逐页讲稿及任务/版本关系；预览缓存可选排除但需能重建 |
| 教案与模板 | DATA_DIR/lesson-plan/<taskId>、templates | 保留上传模板、引用附件、教案JSON与Word版本；内置模板由应用提供，但包内记录应用版本 |
| 问卷与答卷 | questionnaires.json | 保留题目、身份方式、发布名单快照、答卷与版本关系，不只备份CSV |
| 问卷生成任务 | DATA_DIR/questionnaire-ai/<taskId> | 保留需求和已交付初版；恢复时不自动继续调用模型或再次扣额度 |
| 平台业务配置 | settings.json | 保留签到参数、预警规则等；按白名单输出教学设置 |
| 机器配置与凭据 | WorkBuddy可执行路径、skill路径、项目外配置、CLI登录态、DATA_DIR/.secret | 默认不迁移账号凭据和机器专用路径；目标机重新连接。恢复时重新生成签到令牌密钥，不恢复活动二维码 |
| 软件与外部工具 | Node/PowerPoint/CLI、`.local-ppt-skills/config.json`与skill安装等可能在data外 | 不宣称备份可迁移这些依赖；恢复结果列出需重新配置的项目 |

以上存储位置来自代码，不代表已读取真实学生内容。正式实现需确认各版本字段及附件完整性，避免只按目录名盲目归档。

## 建议首版页面

页面标题“数据与备份”，采用工作台/数据看板相同的配色与紧凑层级。

1. 顶部状态区：最近一次成功备份、当前教学数据占用、是否有进行中任务。无记录明确写“尚未创建备份”，不凭文件修改时间推断备份成功。
2. “创建备份”主卡：默认完整教学备份，展示覆盖课程/名单/记录与附件的概况；明确“不包含CLI登录态与外部软件”。创建过程显示当前阶段和已处理文件/容量，有真实进度再显示百分比。
3. “备份记录”表格：创建时间、名称、大小、校验状态、应用/格式版本；下载、查看内容、用于恢复。先保证创建与下载可用，再考虑备份文件管理。
4. “从备份恢复”卡：点击/拖拽上传一个备份包，复用本机Element Plus Upload；上传后先检查和预览，不自动恢复。
5. 底部“存储位置”：实际目录、复制路径、打开目录、按模块的递归容量汇总；不把底层文件名大表作为教师主界面。

首版建议不增加“清空所有数据”“自动清理附件”等无关高风险入口；既有各模块业务删除不移入此页。

## 创建备份流程

创建前检测签到、问卷回收、PPT/教案/问卷生成与自动批改。首版建议有活动任务时提示先完成或暂停业务，备份页不擅自停止它们；不将“复制成功”冒充一致快照。

进入短暂维护状态后阻止新的业务写请求与生成启动；完整复制到独立临时目录，生成清单并校验，再输出备份包。所有写入口和后台写入的覆盖面必须核查，不能只禁用当前页面按钮。复制期间还需验证源文件未变化，失败不登记成功记录。

备份文件与临时工作目录放在教学DATA_DIR之外，避免把旧备份再次打入新备份。备份记录或清单可记录位置；不递归包含备份目录、符号链接/目录联接、半成品tmp文件。失败时保持源目录不变，清理仅限本次明确创建的临时文件。

建议备份包包含格式版本、应用版本、创建时间、数据集统计、文件相对路径、大小和SHA-256。清单用于校验完整性，不意味着文件内容本身安全或来源可信。

附件可能很大。不能直接假设当前JSZip整包加载内存适合全部教学数据；原型不安装依赖，正式实现前评估现有库的容量与流式能力，再确定压缩方式与容量上限。限制必须在开始前说明，超限不得生成截断备份。

## 恢复流程

固定步骤：选择备份 → 检查与预览 → 确认恢复 → 执行与结果。上一步放内容底部左侧。

- 先校验文件类型、包结构、格式/应用版本、清单哈希、JSON结构与ID关系、附件引用。拒绝路径穿越、绝对路径、重复目标路径、符号链接、解压炸弹、超限文件数/容量及无法支持的新格式。不能在正式目录边解压边验证。
- 预览展示“备份内容/当前内容”、备份时间、所需空间、丢失附件与兼容性问题。首版只支持整体替换；不做按课程合并，以免课程/学生/任务ID和版本引用发生冲突。
- 明确提示整体替换会覆盖当前教学数据；恢复前自动创建当前数据的安全快照，失败则不继续。按钮使用红框，最终确认弹窗写出对象及后果；普通取消检查为中性按钮。
- 检测活动业务与并发变更，再由服务端取得维护锁。当前有签到、问卷回收或生成/批改运行时，不自动中断以强行恢复。
- 解压到同盘独立暂存目录，验证完毕后由独立恢复流程停止服务、替换数据目录并重启。不能在仍持有旧缓存/子进程的服务中热覆盖数据。
- 目录替换前保留原目录与恢复事务日志（均在目标DATA_DIR之外）；启动检查失败时回退原目录并给出恢复结果。Windows文件锁、磁盘不足、断电/重启中断必须有可检查的恢复状态，不承诺单次rename能保证整个流程成功。
- 恢复后的旧运行中任务标记为已中断，教师核对后手动重试；不恢复可用中的签到二维码、不自动继续模型任务、不复制外部CLI登录凭据。

同机恢复与换机恢复需要区分：教学数据结构可相同，但换机后的CLI、skill、PowerPoint和路径有效性必须重新核对。首版默认覆盖当前实例，换机助手可后续补充。

## 反馈和权限

仅本机教师端可用，后台也验证Host、请求来源及访问权限。备份包含学生个人信息与答卷，仅保存/下载到用户明确操作的位置，不上传第三方；原型只用虚构信息。

输入/文件错误用行内校验；包检查失败用当前卡片持续提示；后台备份完成用可打开结果的通知；需重启的恢复进度必须由独立状态可查询。恢复过程不靠一个不会跨服务重启保留的Toast表达完成。

## 阶段与验收建议

| 阶段 | 交付 | 验收重点 |
| --- | --- | --- |
| 1 原型 | 状态、创建、记录、检查/恢复步骤、各种异常展示 | 用户理解备份范围与恢复后果；页面入口独立且旧链接可达 |
| 2 备份 | 真实一致快照、清单、下载、记录、容量与活动任务保护 | 隔离源与包逐文件比对；大附件不遗漏；失败不改源数据 |
| 3 恢复 | 结构检查、预览、自动安全快照、维护/重启、回滚 | 隔离实例中恢复后各模块可读；坏包、跨版本、断点、磁盘/锁失败不损坏旧数据 |
| 后续可选 | 定时备份、保留策略、换机配置助手、单课程导入 | 另行确认范围，不把自动删除纳入首版 |
