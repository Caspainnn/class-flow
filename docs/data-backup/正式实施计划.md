# 数据与备份正式实现计划

2026-11-01 用户已通过原型验收并授权正式实现。状态：实现与隔离自测完成，独立代码审查问题已关闭，正式服务已加载；用户正式验收待完成。详见[正式交付与验收](正式交付与验收.md)。

沿用已验收页面及四步恢复；不安装依赖、不上传外部服务、不在真实数据上验证恢复。

1. `server/backup/archive.js`：现有JSZip流式写出ZIP，逐文件清单SHA-256；有界导入、ZIP目录检查、结构及附件引用校验、安全解压。首版压缩包256MB、展开1GB、单文件128MB、15000文件；超限明确拒绝，不部分备份。
2. `server/backup/service.js`与`runtime.js`：DATA_DIR同级独立备份目录、持久化任务/记录、递归容量、活动任务检测、全平台API维护锁及在途请求保护；只在没有活动业务时获取一致快照。
3. `server/backup/restore-worker.js`：独立进程等主服务退出，保留原目录、切换已验证暂存数据、重启并检查专属事务健康标记；失败回滚。恢复前另生成可下载安全备份。旧目录保留，不自动清理。机器连接配置留在目标机，不从包内恢复CLI/可执行路径；旧活动二维码和生成任务不继续。
4. `server/backup/routes.js`和`public/`：本机教师接口、真实下载/上传、四步检查和确认、任务进度与跨重启轮询。导航独立`/backup`，旧`/admin?pane=set#data`兼容。
5. 隔离数据验收：完整往返、篡改/路径/压缩容量/缺附件/版本、活动业务、并发、恢复成功及回滚、权限、实际页面和下载。真实平台仅执行读取、必要无活动任务时加载代码，不执行真实恢复。

完整教学备份覆盖源DATA_DIR的教学文件与软删除记录，排除密钥、临时文件与可重建缓存；settings仅导出教学参数白名单。备份是可读取个人数据的ZIP，界面明确含学生信息，并仅本机可访问；不宣称ZIP加密。
