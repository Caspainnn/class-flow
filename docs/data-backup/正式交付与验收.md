# 数据与备份正式交付与验收

2026-11-01。用户已通过原型验收；正式实现完成，自测通过，正式验收待完成。

入口：[数据与备份](http://127.0.0.1:3000/backup)。侧栏与移动导航已接入，旧`/admin?pane=set#data`由工作区兼容跳转。

## 已实现

- 真实递归容量、教学内容概况、任务条件、备份记录与存储位置；正式页面无虚构记录或模拟恢复。
- 创建包含教学文件与附件的ZIP，SHA-256逐文件清单；流式压缩，源数据变化则不登记成功。备份文件、检查文件、恢复事务和原目录保留在DATA_DIR同级`.inclass-backups-<目录名>`，不打入下一份备份。
- 覆盖课程、名单、课堂、作业与批改原文件、PPT及上传模板、HTML和讲稿、教案及模板、问卷与答卷、教学设置；软删除历史保留。当前页面数量按有效资源展示，包内内容检查可能包含更多历史任务。
- 导出排除隐藏密钥、临时文件、可重建`_visuals`缓存；settings仅输出教学参数白名单，不迁移CLI登录、执行路径或skill机器配置。恢复时保留目标电脑的WorkBuddy/PPT连接配置，重新生成课堂签名密钥。
- 下载前验证备份包哈希。记录显示创建结果，上传恢复时重新验证，不把创建时的校验当成永久有效。
- 点击或拖拽上传ZIP到本机，复用本机Element Plus Upload；校验格式版本、主版本兼容、实际解压量、路径、重复目标、链接、清单、每个文件哈希、核心JSON、课程/批改/任务ID和附件引用。
- 四步恢复：选择、检查、确认、结果。检查展示备份/当前数量与空间需求；勾选知情确认后再打开原生风险弹窗，安全按钮默认聚焦。
- 最终恢复再次检查活动业务及预览后数据变化；创建当前完整安全备份，暂存并复验，再通过独立进程退出旧服务、切换目录、重启并检查本次事务健康标记。原目录保留，不自动删除。
- 失败时先确认新服务退出，再回滚；若无法确认进程退出，保留维护状态，不移动live目录。中断事务支持安全重启回滚与下一次启动恢复，已提交事务不误回滚；所有结果有持久化任务记录。
- 恢复后旧签到结束、回收问卷转为已结束、旧生成任务标记中断，教师核对后手动重试，不自动消耗模型额度。

## 运行保护

检测签到（含迟到有效期）、问卷回收、PPT/教案/问卷生成及自动批改。存在活动业务时拒绝创建/恢复，不代替教师终止任务；导入检查允许先做，但最终恢复仍会复核。

备份或恢复维护期间，所有非备份业务API暂停，包括可能修正状态的GET；在途业务请求尚未完成时不取得维护锁。恢复后的新进程也在事务提交前保持维护。备份与恢复接口均限本机教师端，并检查Host、来源及跨站请求。

## 首版容量与边界

- 压缩包最多256MB；展开教学文件最多1GB；最多15000个文件；单文件最多128MB。
- 单JSON最多32MB；核心元数据JSON合计最多64MB；清单最多4MB，均在创建及恢复两侧一致执行。超限拒绝，不生成“部分成功”的备份。
- ZIP未加密，包含学生信息。保存在本机，可下载另存其他位置；不会上传云端。不包含外部Node/PowerPoint/CLI/skill安装或CLI登录态。
- 整体替换，不合并课程；需要足够磁盘空间同时保留导入文件、安全备份、暂存及原目录。首版不自动清理备份和回滚原目录，不提供全量清空或自动保留期删除。
- 恢复需要重启本机Node服务，界面跨重启查询任务。若操作系统拒绝终止子进程或重启失败，界面明确提示检查状态，原目录和安全备份不删除；断电后的恢复由下次启动检查事务处理。
