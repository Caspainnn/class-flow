# 签到管理整合

- 侧栏课中“发起签到”更名“签到管理”，移除课后独立“签到记录”入口。
- 首页保留一个“签到管理”入口，移除重复历史记录卡片。
- `/session` 内包含“发起签到”和“签到记录”页签，切换时保留正在编辑的题目，不停止现有签到。
- 记录页复用原出勤统计接口及图表、明细、每人累计逻辑，可按课程筛选、按次导出或导出全部记录。
- 没有课程/记录时明确提示，整课导出按钮禁用；切换课程的旧请求响应不能覆盖新选择。
- `/session?tab=records&courseId=...` 支持直达记录；旧 `/admin?pane=dash` 或默认签到看板地址自动跳转，系统设置入口保留。
- 当前归档阶段的“查看签到记录”进入同页记录视图。
- 三个相关页面内联 JavaScript、外壳语法检查通过；`check-session-flow.js`、`check-session-multiple.js` 通过。
- 浏览器验证历史数据加载、发起/历史切换保留题目、无记录课程空态与禁用导出、旧地址跳转；未创建或修改真实签到。
