# 一堂课桌面启动器

已确认范围：双击“一堂课.exe”，隐藏启动本机服务并打开浏览器；重复双击复用托盘和服务；托盘打开平台、日志目录或退出；关闭网页不结束服务。退出前服务端检查签到、批改、问卷、PPT、教案、备份及恢复，无强制终止教学任务入口。

实现选择：复用现有 Node 网页平台和发行包结构，使用 Windows .NET Framework / WinForms 原生托盘启动器，避免增加老师电脑的 Python 或桌面浏览器外壳依赖。基础平台随包携带 Node，AI、PPT/Office 等附加能力仍按 README 单独配置。

验证计划：隔离数据验证服务身份、不相关端口拒绝、停止鉴权、任务阻止退出、空闲停止；编译并运行真实启动器，验证重复启动、托盘及退出。保留现有真实服务，不用真实签到数据做写测试。

本机自测：已编译无控制台 EXE；隔离3047端口验证启动就绪、重复启动复用同一Node PID；退出接口的本机/身份/密钥校验及所有任务保护通过，备份服务及HTTP回归通过。正式3000端口已确认空闲后交由托盘启动器运行，桌面已生成快捷方式。原有教学Word文件改动保留。

界面验证边界：Windows UI工具能列出托盘进程，但本轮未抓取到退出弹窗窗口；确认按钮与默认安全焦点已经实现，仍列为用户待验收，未标记真机UI验收通过。

使用：双击桌面“一堂课”；托盘右键选择打开平台、日志或退出。依赖不完整、端口被其他目录占用时会说明问题，不会停止占用者。服务失联后托盘会提示，可再次打开；恢复事务未完成时不会抢先重启。日志位于logs，课程数据位于data（或DATA_DIR）。

构建：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-launcher.ps1`；发行包：`python tools/build-release.py --skip-exe`。使用Windows自带.NET Framework编译器，不再依赖PyInstaller或开发者绝对路径。发行包携带基础Node及server、xueqing模块，不包含真实教学数据、密钥、账号和本机Python/Office环境。


## 双击无响应修复

现象：Node服务已就绪，但日志缺少ready/browser opened，重复启动只发送信号，没有打开网页。原因：分离启动的Node继承了启动脚本的管道句柄，启动器等待ReadToEndAsync的EOF会一直阻塞，导致ready标志未置位。改为有超时地读取唯一的PID行，等待启动脚本退出后检查服务健康，不再依赖管道EOF。

验证：保留正式Node进程，仅替换托盘；首次与重复双击均记录browser opened。独立3047端口从完全未运行状态冷启动，依次记录server started、ready、browser opened，验证通过；测试完成后已清理隔离服务。发行包同步更新。

## 2026-11-06 桌面快捷方式被360隔离

老师电脑截图显示被隔离的是“一堂课.lnk”，检测名称为virus.lnk-powershell.a。原setup-desktop.ps1确实生成以PowerShell为目标、带隐藏窗口及ExecutionPolicy Bypass参数的快捷方式，与截图检测对象吻合；尚未取得老师电脑的快捷方式原件和360复测，不能据此确认误报。

本轮将快捷方式改为直接指向一堂课.exe，由原生启动器接收--port、--data-dir、--host、--public-origin参数；保留环境变量启动兼容。重新运行安装脚本可迁移本项目的旧入口，其他项目的同名入口仍拒绝覆盖。启动器在计算服务身份和单实例标识之前应用参数，避免自定义数据目录与端口失效。

开发机无360。node tools/check-desktop-shortcut.cjs已在隔离副本编译原生EXE并读取实际生成的.lnk，验证原生目标、保存的参数、实际启动参数解析、自定义端口与数据目录、旧入口迁移、重复配置、环境变量兼容、错误参数拒绝、盘符根目录和空PUBLIC_ORIGIN、其他项目入口保护。node tools/check-desktop.cjs安全退出回归通过；未改动正式服务或教学数据，未重新生成开发机正式桌面快捷方式和在用EXE。

本轮以GitHub main源码更新交付，已完成本地功能自测；未重新制作发行包、未在老师电脑更新，360结果仍待验收。老师电脑的复测步骤及进一步取证见[查杀排查与复测](desktop-antivirus.md)。后台启动现仍使用项目既有PowerShell辅助脚本，不能把本次改动表述为“所有运行环节已移除PowerShell”或“360已放行”。
