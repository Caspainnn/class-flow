# 一堂课桌面启动器

已确认范围：双击“一堂课.exe”，隐藏启动本机服务并打开浏览器；重复双击复用托盘和服务；托盘打开平台、日志目录或退出；关闭网页不结束服务。退出前服务端检查签到、批改、问卷、PPT、教案、备份及恢复，无强制终止教学任务入口。

实现选择：复用现有 Node 网页平台和发行包结构，使用 Windows .NET Framework / WinForms 原生托盘启动器，避免增加老师电脑的 Python 或桌面浏览器外壳依赖。基础平台随包携带 Node，AI、PPT/Office 等附加能力仍按 README 单独配置。

验证计划：隔离数据验证服务身份、不相关端口拒绝、停止鉴权、任务阻止退出、空闲停止；编译并运行真实启动器，验证重复启动、托盘及退出。保留现有真实服务，不用真实签到数据做写测试。

| 编号 | 功能点 | 验收情况 |
|---|---|---|

| 3 | 依赖及端口故障提示、发行包说明 | 待验收⌛️ |


本机自测：已编译无控制台 EXE；隔离3047端口验证启动就绪、重复启动复用同一Node PID；退出接口的本机/身份/密钥校验及所有任务保护通过，备份服务及HTTP回归通过。正式3000端口已确认空闲后交由托盘启动器运行，桌面已生成快捷方式。原有教学Word文件改动保留。

界面验证边界：Windows UI工具能列出托盘进程，但本轮未抓取到退出弹窗窗口；确认按钮与默认安全焦点已经实现，仍列为用户待验收，未标记真机UI验收通过。

使用：双击桌面“一堂课”；托盘右键选择打开平台、日志或退出。依赖不完整、端口被其他目录占用时会说明问题，不会停止占用者。服务失联后托盘会提示，可再次打开；恢复事务未完成时不会抢先重启。日志位于logs，课程数据位于data（或DATA_DIR）。

构建：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-launcher.ps1`；发行包：`python tools/build-release.py --skip-exe`。使用Windows自带.NET Framework编译器，不再依赖PyInstaller或开发者绝对路径。发行包携带基础Node及server、xueqing模块，不包含真实教学数据、密钥、账号和本机Python/Office环境。
