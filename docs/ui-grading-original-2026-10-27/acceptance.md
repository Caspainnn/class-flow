# 提交原件复核（2026-10-27）

- 成绩表以“查看原件”为主要复核入口，直接关联该学生匹配的上传文件；多份提交分别编号。
- 评分详情改为独立“评分明细”按钮，保留逐题理由、总评与人工改分，不再整行点击展开。
- 未关联提交文件显示“无提交原件”；缺少成绩时评分明细提示核对提交和匹配。
- PDF、TXT、MD 原文件可在浏览器打开；Word、压缩包等下载原件查看，不声明在线预览支持。
- 文件读取仅限批次登记文件和该批次目录，拒绝越界路径及目录外符号链接；已删除批次与缺失文件有明确错误。
- 沿用教师接口的仅本机访问限制。文本按纯文本返回，禁止嗅探为 HTML。
- `tools/check-grading-original.js`、`tools/check-grading-context.js` 通过，后端语法检查通过。
- 浏览器使用独立虚构数据确认5名学生入口正确，读取陈一禾原件内容，展开评分明细可继续改分。未调用模型或修改真实成绩。
