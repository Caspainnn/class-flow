# 第三章 课程管理

本章主要介绍如何在“一堂课”中创建课程、录入和维护学生名单、修改课程信息、查看课程概要以及删除课程，为后续签到、作业管理和学情分析做好准备。

## 3.1 概述

课程管理用于集中维护课程名称、学期、课程备注和学生名单。教师在左侧导航中点击“课程管理”，即可查看课程列表，如图1所示。

![图1. 课程列表与常用入口](图片/第三章-图1-课程列表.png)

图1. 课程列表与常用入口

① 点击“＋ 新建课程”，按“基本信息→名单录入→确认完成”的顺序创建课程。

② 输入课程名称进行搜索，或选择学期筛选课程；同时使用时，列表显示同时满足两个条件的课程。

③ 查看课程卡片中的课程名称、学期、名单人数和签到记录次数，点击“管理课程”或“继续完善”进入维护页面。

课程有学生名单时显示“已就绪”；尚无名单时显示“待录入名单”。“已就绪”表示已录入名单，不代表课件、教案等其他准备工作全部完成。

## 3.2 新建课程

在课程列表右上角点击“＋ 新建课程”，按以下步骤完成课程准备。

### 3.2.1 填写基本信息

第1步：填写必填的“课程名称”和“学期”，分别最多80个、40个字符，例如“高等数学（上）”“2026 秋”。可在课程名称中注明班级，便于查找。

第2步：按需填写“课程备注”，例如教学对象或其他说明，最多300个字符，也可留空。

第3步：点击“下一步：名单录入”。系统保存基本信息后进入下一步；缺少必填项时，按提示补齐后继续。

注意：进入名单录入后，课程基本信息已经保存。此时返回列表会保留课程；需要撤销时，按3.5节删除课程。

### 3.2.2 录入学生名单

第1步：选择“上传表格”，点击上传区域或将文件拖入。支持.xlsx、.csv，每次一份，最大20MB；前两列依次为学号、姓名。Excel读取第一张工作表，.xls须先另存为.xlsx。

第2步：也可选择“粘贴名单”，每行一人，学号与姓名以逗号、空格或Tab分隔，点击“预览并加入名单”。学号须为4位及以上数字，姓名不能为空。

第3步：核对“当前名单”。有效学生会直接加入，重复学号或格式错误会单独提示；修正被跳过的内容后重新录入。维护方法见3.3节。

第4步：点击“下一步：确认课程”；暂不录入可点“稍后录入名单”。粘贴框中有未处理内容时，须先处理再继续。

### 3.2.3 确认完成

第1步：核对课程名称、学期、备注和名单人数。需调整时，点击对应区域的“修改”，或使用内容底部左侧的“上一步”返回。

第2步：点击“完成并返回课程列表”。已录入名单时，卡片显示“已就绪”；未录入时显示“待录入名单”，可稍后补充。

## 3.3 学生名单维护

在课程卡片中点击“管理课程”或“继续完善”，进入课程维护页。“课程名单”区域支持追加名单和移除学生。图2为该区域在窄屏下的显示，操作与电脑端相同。

![图2. 课程名单的录入与核对](图片/第三章-图2-课程名单.png)

图2. 课程名单的录入与核对

① 选择“上传表格”或“粘贴名单”。两种方式均向当前课程追加有效学生，不会用新名单整体替换原名单。

② 点击或拖拽上传表格；使用粘贴方式时，输入内容后点击“预览并加入名单”。核对新增人数、跳过行数和当前总人数，按提示修正重复或错误数据。

③ 在学生名单中核对学号、姓名，确认需要移除后点击该行的“移除”。移除会直接生效，已有历史记录保留；名单变化仍可能影响按当前名单计算的历史统计，请谨慎操作。

注意：上传、加入名单和移除学生均会直接保存，不需要再点击右侧的“保存信息”。同一课程不能重复导入相同学号；重复导入不会自动覆盖姓名。

## 3.4 课程信息与概要

课程维护页将课程概要、学生名单、基本信息和删除入口集中展示，无需像新建课程时逐步切换。

### 3.4.1 修改课程信息

第1步：在课程卡片中点击“管理课程”或“继续完善”，进入需要修改的课程。

第2步：在右侧“基本信息”区域修改课程名称、学期或课程备注。课程名称和学期不能为空，长度限制与新建课程时相同。

第3步：点击“保存信息”。看到“课程信息已保存”的提示后，核对页面标题、学期和备注是否正确。仅输入文字而未保存，不会完成课程基本信息的修改。

修改课程名称、学期和备注后，学生名单及已有记录仍关联到原课程。同一门课换了授课班级或进入新学期、需要独立保存教学记录时，建议新建课程。

### 3.4.2 查看课程概要

页面顶部显示当前课程的四项概要信息：

（1）课程名单：当前课程名单中的学生人数。追加或移除学生后，该人数会随之更新。

（2）签到记录：该课程已有的签到记录次数，不是到课学生人数；查看具体出勤情况时，应进入签到相关页面。

（3）课程作业：该课程关联的作业数量；当前统计同时包含未绑定具体作业的独立批改批次，不表示已经完成批改或提交的学生人数。

（4）准备状态：已有学生名单时为“已就绪”，没有名单时为“待录入名单”。该状态用于提示名单准备情况。

查看或修改完成后，点击页面右上角“返回课程列表”，即可选择其他课程。若刚修改过基本信息，请先点击“保存信息”。

## 3.5 删除课程

课程不再需要使用时，可在课程维护页删除。操作前应核对课程名称、学期、名单人数和关联记录；重要教学资料建议先通过“数据与备份”保留完整备份。

### 3.5.1 删除操作

第1步：在课程列表中找到目标课程，点击“管理课程”或“继续完善”。核对页面顶部的课程名称和学期，确认没有选错课程。

第2步：在课程维护页右下方找到“删除课程”区域，点击红框“删除课程”按钮，展开确认区域。

第3步：阅读确认区域中的课程名称、学生人数、签到记录次数及删除后的影响。不再删除时，点击“取消”。

第4步：确需删除时，点击“确认删除课程”。操作成功后返回课程列表，并显示“课程已删除，原始数据已保留”；核对该课程已从列表中移除。

### 3.5.2 删除限制与影响

（1）该课程正在进行签到，或有正在运行的作业批改时，系统会阻止删除，并提示先结束相应任务。按正常流程完成或结束任务后，再返回核对并操作。

（2）删除后，该课程及其关联作业、批改记录会从相关日常业务入口隐藏；原始名单、签到记录和文件会保留。原始数据保留不代表可以在页面中直接恢复课程。

（3）删除前请完成必要备份。当前课程管理页面没有提供恢复按钮；不要通过再次创建同名课程来替代恢复，新的同名课程不会自动继承原课程记录。

（4）“返回课程列表”和“取消”仅用于返回或取消当前确认，不会回退此前已经保存的课程信息或名单变更。
