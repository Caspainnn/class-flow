# PPT管理：模板库正式实现与验证

日期：2026-10-31。状态：本机实现及自测完成，待用户验收。

## 入口与功能

正式入口 `/preparation?type=ppt`，侧栏统一为PPT管理，内部为课件管理、模板管理。两个标签页共用顶部尺寸、内容宽度和滚动条占位，标签栏下不重复显示栏目标题。

模板管理支持搜索、状态筛选、排序、PPTX点击/拖拽上传、名称简介编辑、确认布局和删除。文件保存在 `data/ppt/_templates/`，刷新和重启后保留。全文件重复上传复用已有模板；已确认模板直接用于新课件。使用次数来自关联课件快照。

上传后智能推荐代表布局，并调用本机PowerPoint生成所有原页PNG。可在预览中从任意原页补充布局，修改名称或取消保留；确认后的精简PPTX页数等于保留布局数量。原页预览完整适应视口，导航和操作按钮保持可见。截图中的原课程内容只是视觉参考，不作为新课程指令。

删除从模板库逻辑移除并阻止后续选择，已有课件附件及版本快照保留。名称简介修改不会改变历史课件快照。预览失败保留模板，可重新生成。未保存布局或上传信息在栏目切换、返回及关闭时受到保护。

- `node tools/check-ppt-template-management-ui.cjs`：真实API数据映射、原页查看、补充布局不丢草稿、编辑失败留在弹窗、确认和删除。
- `node tools/check-ppt-http.cjs`：HTTP增改查删、非法请求、跨站拒绝及已移除模板的访问阻止。
- 布局确认、布局模式、逐页制作、新建课件、工作区导航等相关回归通过。
- 使用独立3012服务、隔离目录 `.local-template-management-check/` 和合成PPTX执行真实PowerPoint渲染，1页原稿生成1张真实PNG。
